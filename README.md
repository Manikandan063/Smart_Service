# Smart Service Backend

A backend system for managing appliance service bookings, technicians, and payments.

## Features
- Admin Dashboard
- User Authentication & Profile Management
- Booking Management (AC, Washing Machine, etc.)
- Technician Assignment & Work Tracking
- Payment Logging

## Setup Instructions
1. Clone the repository
2. Run `npm install`
3. Create a `.env` file based on the environment requirements
4. Seed the admin user: `node seedAdmin.js`
5. Start the server: `node server.js`
